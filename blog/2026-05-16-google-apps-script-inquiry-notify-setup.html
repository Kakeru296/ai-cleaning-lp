Google Apps Scriptで問い合わせ通知を自動化する設定ガイド

・Google Apps Scriptで問い合わせ通知を自動化する基本的な仕組み
・Google Formやスプレッドシートとの連携手順
・通知メール遅延を防ぎ、リアルタイム対応を実現する設定方法

Google Apps Scriptによる問い合わせ通知とは

サービス業の経営では、顧客からの問い合わせに迅速に対応することが売上向上に直結します。Google Apps Script（GAS）を活用すれば、Google Formやスプレッドシートに投稿された問い合わせを自動的にメール通知する仕組みが作れます。

従来のメール自動返信機能では通知の遅延が生じることもありますが、GASを使えば最短数秒以内に管理者へ通知が届きます。システムエンジニアの力を借りずに実装でき、小規模事業者から大規模企業まで対応可能です。

Google Formとスプレッドシート連携での設定手順

まずGoogle Formで問い合わせフォームを作成し、回答をスプレッドシートに自動保存する設定をします。

ステップ1：Google Formの準備
Google Formで「名前」「メールアドレス」「問い合わせ内容」などの項目を作成します。フォームの設定画面で「回答」タブを選択し、緑色のスプレッドシートアイコンをクリックして、新しいスプレッドシートを作成します。

ステップ2：スプレッドシートでGASを開く
スプレッドシートメニューの「拡張機能」→「Apps Script」をクリックします。新しいタブでエディタが開きます。

ステップ3：通知スクリプトの設定
以下のコードをエディタに貼り付けます：

function onFormSubmit(e) {
const range = e.range;
const values = range.getValues()[0];
const email = 'your-email@gmail.com';
const subject = '新しい問い合わせが届きました';
const message = '氏名：' + values[1] + '\n\nメール：' + values[2] + '\n\n内容：' + values[3];
GmailApp.sendEmail(email, subject, message);
}

メールアドレスと項目番号は、スプレッドシートの列順に合わせて調整してください。

トリガー設定でリアルタイム通知を実現

スクリプトを作成したら、トリガーを設定して自動実行を有効にします。

Apps Scriptエディタの左側メニューから「トリガー」をクリックし、右下の「トリガーを作成」ボタンを選択します。設定画面では、関数名を「onFormSubmit」、実行するイベントを「フォーム送信時」に指定します。

この設定により、Google Formに新しい回答が投稿されると、数秒以内に管理者にメール通知が届きます。実装後は運用データを確認し、通知の到着時間を計測することをおすすめします。多くの企業では平均2～3秒以内の通知実績があります。

まとめ

Google Apps Scriptを活用した問い合わせ通知の自動化は、追加コスト不要で導入でき、顧客対応の質を大きく向上させられます。設定自体は30分程度で完了します。今回ご紹介した手順に従い、サービス業の経営効率化に役立ててください。定期的にログを確認し、スクリプトの改善を重ねることで、さらに精度の高い通知システムを構築できます。
